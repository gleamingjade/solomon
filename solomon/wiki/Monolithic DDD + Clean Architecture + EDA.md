# Monolithic DDD + Clean Architecture + EDA

Monolithic DDD + Clean Architecture + EDA 의 장점은 이거고
단점은 도메인 로직이 얼마 없는 놈이 쓰면 도메인 로직 테스트가 쉬운 것도 별 장점이 아님
db가 잘 동작하는지 쿼리 효율적으로 나가는지 인덱스 타는지 이게 핵심이라 큰 장점이 없음

여기서 인프라 변경 가능성이 크게 없는 경우에는 복잡해지기만 함

근데 경험차 한 번 해보고 싶음..

나중에 유동적으로 적용할 수 있도록 이 프로젝트는 공부 차원에서 최대한 모놀리스 구조에서 정석으로 아키텍처를 따라가보고자 함.
